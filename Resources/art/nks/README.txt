Massive PSXL - NKS artwork (provisional)
=======================================

IMPORTANT: The exact artwork sizes/formats required for NKS (Native Kontrol Standard)
must be checked against Native Instruments' NKS Developer Kit / SDK documentation.
The sizes used here are PROVISIONAL placeholders and may need to be regenerated:

  plugin_logo_256.png / plugin_logo_128.png   plugin logo (square)
  banner_1200x600.png / banner_600x300.png    hero banner with product name
  category_*.png  (512x512)                   category tiles: bass, leads, pads, plucks,
                                              keys, drums, fx, sequence

All artwork is original, generated by tools/gen_art.py (deterministic, seeded).
To change sizes, edit gen_nks() in that script and re-run it.
